# Dev

## Summary
開発をはじめるための手順を記載する

## ローカル環境で起動する手順
1. `pnpm install`
2. `pnpm dev`
3. `pnpm start`

## モックデータで動作確認したい場合
自身の git リポジトリのブランチを直接いじらずに、削除・強制削除まわりの動作を試したいときは以下を使う。

1. `pnpm install`
2. `pnpm dev`
3. `pnpm start:mock`

`pnpm start:mock` は OS の一時ディレクトリ配下に使い捨ての git リポジトリを作り直し、いくつかのフィクスチャブランチ（マージ済みのものと未マージのもの）を用意したうえで、そのリポジトリを対象に home-pruner をそのまま起動する。home-pruner 自体のコードは変更されないため、実際の削除・強制削除フローがそのまま試せる。実行が終わっても自身の git リポジトリのブランチには一切影響しない。
